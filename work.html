Our work

Two products.
Both live.
Both useful.

Worth Looking Up answers “when should I step outside?” Fruiting Forecast answers “where is it worth looking?” Both were built here, both run on their own domains, and neither has a demo mode.

Why these two

We built both products for ourselves rather than for a client. That makes them a fair test of how we work: start with a narrow question, publish the limits along with the answer, and leave the person using it in control.
